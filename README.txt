项目名称：Minimal Coding Agent
Git 仓库：https://github.com/happy-299/CodingAgent

运行：需要 Python 3.10+，无需安装依赖。在 .env 中配置 DeepSeek API Key，执行 python3 coding_agent.py 进入交互模式；默认 TUI 使用固定高度活动区、底部输入/状态栏和语义化配色卡片，并通过逐行差分刷新保持流式输出稳定。计划固定在活动区顶部；每轮思考卡片位于对应正式输出之前，推理时在卡片内自动滚动，输出开始后自动收起；/thinking 可切换最近一轮思考，鼠标滚轮可回看其他活动记录，--plain 可切换纯文本。也可用 --workspace 指定项目。

设计：早期模型需要 list/read/write/search 等窄工具帮助行动；随着大模型的代码、Shell 和长上下文能力增强，这些工具逐渐成为 ls、rg、sed、Python 的重复封装，并增加 schema 占用与选择成本。因此项目以可组合的 terminal 为唯一执行工具，另提供只维护状态的 update_plan，让 agent 显式规划并追踪进度。只有终端无法表达、评测持续失败或需要独立授权边界时才新增工具。

实现：项目不使用 Agent 框架、SDK 或托管代码执行，只用标准库直连 DeepSeek 原生 tool calling。自行维护多轮历史、reasoning_content、有限工作记忆、计划、工具调用与结果；上下文压缩保留完整协议单元。terminal 返回结构化退出码、输出长度和截断状态，启用 pipefail，不继承敏感环境变量，超时终止进程组。模型可先探索再决定是否规划；探索过久与计划停滞会触发通用检查点；API 支持 SSE 流式重试；输出达到 token 上限可保留上下文续写；完成审计与最大轮数共同保证可靠终止。

验证：52 项框架测试全部通过，包含固定布局、固定计划、逐轮思考时间线、语义配色、差分刷新、Markdown、中文边框对齐和滚动行为测试。真实 V4 Flash 完成多个修复任务和从空目录推进 2048；冷启动日志暴露的范围膨胀、验证假阳性、文本化工具协议和上下文成本继续转化为通用的规划、预算、证据检查、协议恢复与分层上下文机制。任务名称与实现特征不进入系统提示词或控制分支。
