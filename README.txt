项目名称：Minimal Coding Agent
Git 仓库：https://github.com/happy-299/CodingAgent

项目简介

Minimal Coding Agent 是一个简单而完整的编程智能体，使用 Python 标准库直连 DeepSeek 原生 tool calling，在真实工作区自主完成编程任务。

如何运行

在 .env 中配置 OPENAI_API_KEY 后运行：

python3 coding_agent.py

指定项目：

python3 coding_agent.py --workspace /path/to/project

设计理念：把舞台还给模型

随着模型能力提升，Agent 设计的重心应从“不断增加工具、规则和流程”转向“主动减少不必要的中间层”。关键问题不再是“还能为模型增加什么”，而是“最少需要给它什么”。模型已从训练中获得阅读代码、使用 Shell 和解决问题的能力；本项目因此采用最小正交接口：宿主提供稳定边界，模型负责判断与行动。

terminal(command, timeout) 是统一执行入口。模型通过 Shell 组合现有命令，完成探索、读写、运行与验证；一个高表达力接口减少了工具描述和选择成本，同时保留完整行动空间。update_plan 只维护结构化待办与进度，是模型按需使用的状态能力：简单任务可以直接执行，复杂任务再自主规划和调整。

提示词沿用相同原则。除用户目标和安全边界外，探索深度、是否规划、使用哪些命令、是否新增测试、如何验证及何时结束，均由模型结合实际任务判断。提示只提供决策原则与证据标准，不枚举任务类型或预写解法。模型通常先做最小而充分的侦察，理解项目后再行动。

TDD 为行动提供可执行反馈。Agent 从需求中提炼可失败的验收标准，由模型判断编写或复用测试，再完成最小实现并依据证据迭代。terminal 的结构化结果进入“探索—行动—观察—调整”循环；工作记忆和历史压缩保留任务、计划与关键证据，完成审计据此判断是否自然退出。

SSE 流式交互、错误恢复和安全轮次边界保证过程清晰可靠。Minimal 并非减少能力，而是减少不必要的中间层，让模型已有能力更直接地作用于真实工程环境。
